真ん中のド（Middle C）から始める、ピアノ入門アプリです。

キーボードをつないで短いレッスンを進めると、Middle C があなたの弾く音をひとつ残らず聴き取ります。鍵盤を探している間は待ってくれて、準備ができたらカウントを出してくれるので、リズムに合わせて弾く練習もできます。

どんな鍵盤でも
• USB-MIDIキーボード：電子キーボードをiPhone、iPad、Macにつないで電源を入れるだけ。すぐに認識され、ドライバは不要です。
• アコースティックピアノ：MIDI端子がなくても大丈夫。マイクをオンにすると、Middle C がピアノの音を聴いて、どの鍵盤を弾いたかを判断します。音はデバイス上で解析され、録音されることはありません。
• キーボードがまだない方も：画面上の61鍵キーボードですぐに始められます。iPhoneとiPadではマルチタッチに対応し、Macではパソコンのキーボードで白鍵を弾けます。

2つの練習モード
• 練習モード：音楽があなたを待ちます。次に弾く鍵盤が使う指とともに光り、正しい鍵盤を押すまで先に進みません。
• リズムモード：1小節分のクリックでカウントが入り、譜面が一定のテンポで流れます。弾いた音はすべて「ぴったり」「早い」「遅い」「ミス」で判定されます。

初心者のためのコース
8つのユニット、27の短いレッスンで、真ん中のドを見つけるところから、左手で和音を弾きながらメロディを演奏するところまで進みます。1つのレッスンは数分で、前のレッスンの内容を少しずつ積み上げていきます。
• はじめての鍵盤
• 拍を感じる
• 楽譜を読む
• 左手
• 両手で弾く
• 速い音符
• 5つの音の先へ
• 和音

自分のペースで弾ける18曲
「ホット・クロス・バンズ」や「よろこびの歌」から、「アメイジング・グレイス」「メヌエット ト長調」「エリーゼのために（冒頭）」まで、伝統曲とクラシックの名曲を収録。右手、左手、両手のいずれでも練習でき、速さは60%、80%、100%から選べます。

自由演奏
好きなように弾くと、ト音記号とヘ音記号の五線譜に音符が音名とともに表示されます。音符の位置を覚えるのにぴったりです。

それぞれのデバイスに最適化
• Mac：61鍵すべてを画面に表示し、本物のピアノの音で鳴らします。
• iPad：譜面台に立てて、キーボードをUSBポートにつなげます。
• iPhone：縦向きでも横向きでも。曲に必要な範囲の鍵盤を表示します。
一度入手すれば、3つのデバイスすべてで使えます。

プライバシー
アカウント不要、広告なし、トラッキングなし。Middle C はデータを一切収集せず、インターネット接続なしで動作します。進み具合はお使いのデバイスに保存されます。
